# 轻场

**繁琐退场，精彩上场。**

轻场是一款面向三角洲主播和打手的 Windows 本地工作台。它把直播准备、账号安排、订单记录和费用核对等事情放在一个地方，让你少翻记录、少切换工具。

当前版本：**0.14.0 内测版**。轻场承诺永久免费，项目自身源码采用 GPL-3.0-only 许可证。

## 功能介绍

### 主播工作台

- **开播准备**：检查麦克风声音、网络状况和直播前的准备事项。
- **账号安排**：整理上号资料，记录账号是否已经上过或打过。
- **运行监测**：查看电脑硬件和游戏运行数据，并按需设置提醒。
- **精彩时刻**：直播时标记时间点，下播后导出记录，方便查找素材。
- **直播工具**：制作透明背景标题、调整画面滤镜，使用直播形象助手。

### 打手工作台

- **租号管理**：整理租号资料，查看使用状态，支持批量导入。
- **订单与换号**：记录一笔订单中使用的多个账号和各段余额。
- **费用与结算**：核对租号费用、收入和其他支出，确认订单净收入。
- **每日目标**：查看已结算收入和距离目标的差额。

### 其他工具

轻场还提供游戏与电脑设置、卡顿排查、优化前后数据对比，以及本地加密备份和恢复入口。

精彩时刻记录的是时间节点，需要自行保存直播回放和剪辑视频。开播、切换直播场景及导入滤镜等操作，需要在直播软件中完成。硬件读取和外部软件的兼容情况，可能因设备与版本不同而有所差异。

## 安装与使用

轻场目前支持 **Windows 10 及以上的 64 位系统**。下载 0.14.0 安装包并按提示安装，打开后选择“我是主播”或“我是打手”，即可进入对应工作台。

软件还在内测中。使用过程中遇到问题，或对功能有建议，欢迎反馈。

## 本地数据与备份

轻场的数据默认保存在当前 Windows 用户的本机目录 `%APPDATA%\轻场`。你可以在软件内创建加密备份，换电脑时通过备份恢复数据。

**请妥善保管备份密码。**备份中可能包含账号资料等信息，遗忘密码后无法通过软件找回。

## 从源码运行

开发环境需要 Windows x64、Node.js 和 npm。本项目已使用 Node.js 24.16.0、npm 11.13.0 验证安装与构建；依赖版本由 `package-lock.json` 锁定。

在项目根目录执行：

```powershell
npm ci
npm start
```

默认启动会使用当前用户的轻场数据。开发和测试时，可以先指定独立数据目录：

```powershell
$env:QINGCHANG_DATA_DIR = Join-Path $env:TEMP 'qingchang-dev-data'
npm start
```

运行自动化测试：

```powershell
npm test
```

## 构建 Windows 安装包

构建安装包需要安装 Inno Setup 6。安装完成后，在项目根目录运行：

```powershell
npm ci
npm run dist
```

构建过程会先生成 `release/win-unpacked/` 程序目录，再生成 `release-inno/轻场-0.14.0-安装包.exe`。

如果 Inno Setup 没有安装在默认位置，请在构建前设置编译器路径：

```powershell
$env:INNO_SETUP_COMPILER = 'D:\Tools\Inno Setup 6\ISCC.exe'
npm run dist
```

## 项目结构

```text

src/           直播形象助手界面
assets/        图标、角色素材和本地语音模型

vendor/        硬件监测、驱动和显卡配置相关工具
build/         安装器界面素材
test-support/  测试辅助代码
tools/         构建和图标检查脚本
```
